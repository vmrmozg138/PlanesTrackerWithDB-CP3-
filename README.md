# Проект "Трекер самолетов с записью в БД"

## Описание
### Трекер самолетов использует публичные API для показа самолетов в воздушном пространстве стран в реальном времени. Это был предыдущий проект, наработки которого использованы здесь. 

## Установка
Клонируйте репозиторий:
```
git clone https://github.com/vmrmozg138/PlanesTrackerWithDB-CP3-.git
```
## Возможности 
* получение всех самолетов, летящих над заданной страной
* сортировка списка самолетов
* сравнение(по скорости и высоте)
* выдача top-N из списка самолетов
* запись в json-файл
* теперь вручную вводятся 4(можно больше) страны и собираются самолеты по ним
* полученная информация пишется в БД
* для агрегации инфрмации уже используется БД(через запросы)
