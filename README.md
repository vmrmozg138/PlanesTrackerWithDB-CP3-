# Проект "Трекер самолетов"

## Описание
### Трекер самолетов использует публичные API для показа самолетов в воздушном пространстве стран в реальном времени.

## Установка

## Возможности 
* получение всех самолетов, летящих над заданной страной
* сортировка списка самолетов
* сравнение(по скорости и высоте)
* выдача top-N из списка самолетов
* запись в json-файл
